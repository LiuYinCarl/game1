# 塔防（tafang）

仿《王国保卫战》的 2D 塔防游戏，使用 **Godot 4.7**（GDScript）开发。
多关卡模式：**6 个设计关卡**、开始界面、进度存档与星级评价、**4 种防御塔**、
**12 种敌人**（物理/魔法抗性 + 飞行单位）、建造/升级/出售、金币与生命、
胜负结算、粒子特效、主题 UI、背景音乐与程序化音效。

## 打开与运行

1. 安装 Godot 4.7 或更高版本（本机使用 Steam 版 Godot 4.7.1）。
2. 打开 Godot 项目管理器 → **导入** → 选择本目录的 `project.godot`。
3. 打开项目后按 **F5** 开始游戏（主场景为开始界面 `scenes/start_menu.tscn`）。

命令行方式：

```bash
# 运行游戏（开始界面）
godot --path .

# 无头冒烟测试：10 倍速自动建造打穿指定关卡（0-5），输出每波状态与各塔开火统计
# （后期关卡波次多，帧数上限建议 18000）
godot --headless --path . scenes/main.tscn --quit-after 18000 -- --smoke --level=0

# 截图模式：自动建塔开波，输出截图到 /tmp/tafang_*.png（对开始界面同样有效）
godot --path . scenes/main.tscn --quit-after 700 -- --shot --level=0

# 自动化测试套件（189 项检查，退出码反映结果，可接 CI）
godot --headless --path . scenes/main.tscn --quit-after 600 -- --test

# 难度曲线图：输出第 N 关的敌我强度曲线到 /tmp/tafang_chart_LN.png
godot --path . scenes/main.tscn --quit-after 400 -- --chart=13
```

## 打包发布

```bash
./build.sh    # macOS / Linux 上一键导出 Windows EXE 与 macOS APP 到 builds/ 目录
```

```bat
build.bat     # Windows 上一键导出（同样输出两个平台到 builds\ 目录）
```

- `builds/tafang_windows.exe`：**单文件**（资源已内嵌），直接发给他人即可双击游玩
- `builds/tafang_mac.zip`：解压出 `tafang.app`（Universal：Intel + Apple Silicon 均可）
- Godot 可执行文件位置可用环境变量覆盖：`GODOT_BIN=/path/to/Godot ./build.sh`；
  `build.bat` 会自动搜索 Steam 版与独立安装版 Godot，找不到时同样用
  `set "GODOT_BIN=C:\路径\Godot.exe"` 指定
- 导出配置见 `export_presets.cfg`（预设名：Windows / macOS）
- 注意：
  - Windows 版 EXE 图标是 Godot 默认图标（自定义 exe 图标需要在 Mac 上装
    rcedit + wine，如需可后续补充）；国内杀软对无签名的游戏 EXE 可能误报，属正常现象
  - macOS 版为 ad-hoc 签名：接收方首次打开若被 Gatekeeper 拦截，
    需右键 → 打开，或到"系统设置 → 隐私与安全性"里允许

## 玩法

- 开始界面选择关卡（共 6 关：翠绿小径 / 河畔弯道 / 回旋谷 / 双峰峡谷 / 迷雾沼泽 / 王城决战），
  通关解锁下一关，按剩余生命评 1-3 星（≥18 命 3 星，≥12 命 2 星），进度自动存档
- 点击地图上的**石板建造点** → 建造菜单（箭塔 70 / 法师塔 100 / 炮塔 125 / 兵营 110），
  每种塔标注定位与伤害类型：单体速射·物理 / 高伤爆发·魔法 / 范围溅射·物理 / 出兵拦截·物理
- **伤害类型与抗性**：箭塔/炮塔/兵营造成物理伤害，法师塔造成魔法伤害；
  敌人各有抗性（如重甲武士受物理 ×0.45、魔法 ×1.6，幽魂几乎免疫物理），
  **点击场上敌人**可查看其生命/速度/赏金与抗性面板，按敌人构成配塔是通关关键
- **兵营**派出士兵在集合点拦截路面敌人近战对拼，阵亡后自动补兵；
  塔菜单里"移动集合点"后点击道路可改驻守位置；**飞行单位无法被拦截**，
  只能靠箭塔/法师/炮塔对空击落
- 点击已建的塔 → 查看**属性面板**（伤害/攻速/射程/DPS），**升级**时显示数值变化预览
  （最高 3 级）或**出售**（返还 70% 造价）；每个等级外观不同（法师塔更换导弹架造型，
  箭塔/炮塔染色并放大，另有等级黄点）；建造/升级按钮随金币实时亮起
- 敌人共 **12 种**：哥布林、哥布林工兵、兽人、兽人萨满、重甲武士、掠夺者装甲车、
  食人魔、巨魔王（Boss），以及飞行单位飞碟、侦察机、轰炸机、幽魂；
  第 2-6 关波次按解锁节奏逐步引入
- 底部按钮**开始下一波**，波次结束后 **20 秒倒计时自动开波**
  （按钮上显示进度条与剩余秒数，随倍速缩放、暂停时冻结）；
  旁边按钮切换 **x1/x2/x3 倍速**；开局与波次间隙会**预告下一波敌人构成**
- 右上角：**菜单**（返回开始界面）、**测试**（加金币/生命、清空敌人、暂停/继续、音乐开关）
- 敌人冲进城堡扣生命（屏幕红闪 + 震屏 + 警报音），归零失败；守住整关全部波次获胜
- 存档位于 `user://save.json`（解锁进度与每关最高星级）

## 代码架构

```
project.godot          项目配置（主场景=开始界面、1920x1080、GameState 自动加载）
scenes/
  start_menu.tscn      开始界面（关卡选择）
  main.tscn            关卡场景（仅根节点，内容由代码生成）
scripts/
  game_state.gd        全局状态单例：当前关卡、解锁进度、星级、存档读写
  start_menu.gd        开始界面：手绘草地背景 + 六关卡片（锁定/星级显示）
  main.gd              游戏主管理器：
                       - LEVELS 六关数据目录（路径/建造点/初始金币生命/血量成长/波次）
                       - _compose_waves() 参数化波次生成器（第 2-6 关）
                       - MapDrawer 内部类：分层地图绘制（斑驳草地/道路投影/装饰阴影/
                         城堡/传送门/暗角/射程预览/悬停高亮）
                       - 波次调度、金币生命、建造/升级/出售
                       - 特效系统（粒子/爆炸/飘字/红闪/震屏）与全部 UI
                       - 程序化音效合成（_synth_* 系列函数）
  enemy.gd             敌人：沿路径移动、渐变血条、物理/魔法抗性、飞行、被士兵拦截、受击闪白
  soldier.gd           兵营士兵：驻守集合点、拦截敌人近战对拼、迷你血条
  tower.gd             防御塔：索敌开火或派兵拦截（兵营）、平滑转向、逐级数值表、伤害类型
  projectile.gd        投射物：追踪弹道、发光拖尾、按伤害类型结算、单体/溅射伤害
assets/
  td/                  Kenney Tower Defense Top-Down 贴图（地图装饰，CC0）
  spire/               Foozle Spire 系列贴图（塔/敌人/灵体，CC0）
  fx/                  Kenney Particle Pack 粒子贴图（CC0）
  ui/                  game-icons.net 图标（CC BY 3.0）
  audio/               背景音乐（CC BY 4.0）；音效为运行时程序化合成，无外部素材
```

### 关键设计

- **数据驱动关卡**：`main.gd` 的 `LEVELS` 目录集中定义六关的路径折点、建造点、
  初始资源与难度系数；城堡位置按路径末端方向自动推算；第 1 关使用手工波次
  `WAVES_L1`，第 2-6 关由 `_compose_waves(波数, 预算)` 生成
- **逐级数值表**：每种塔的 `levels` 数组显式定义 1-3 级的伤害/攻速/射程/溅射
  （兵营为士兵数/生命/攻击/补兵间隔）与升级花费，调平衡只改表，不用乘法系数换算
- **伤害类型系统**：塔标 `damage_type`（physical/magic），敌人 `armor` 字典给出
  各类型受伤倍率，`take_damage(amount, dtype)` 统一结算；配合飞行/地面与
  拦截机制形成克制循环（重甲怕魔法、幽魂怕魔法、魔抗怪怕物理、飞行只能对空打）
- **无场景文件依赖**：关卡内所有节点都在代码中构建，加新关卡只需在
  `LEVELS` 追加一个字典
- **建造点校验**：所有建造点到路径距离 ≤185（小于最短的炮塔射程 190），
  新设计关卡时应复核（可用脚本计算各点到路径折线段的最近距离）
- **特效/UI 复用**：`spawn_particles(pos, opts)` 一个函数组合出全部粒子效果；
  `_panel_style()` / `_style_button()` 统一深色金边 UI 风格
- **程序化音效**：`_setup_sfx()` 运行时合成 16-bit WAV（开火/爆炸/建造/金币/
  警报/胜负），通过 `play_sfx()` 播放并带随机音高，无外部音频素材依赖
- **存档**：`GameState` 自动加载单例负责进度与星级，胜利时写入 `user://save.json`；
  冒烟测试（`--smoke`）不写存档
