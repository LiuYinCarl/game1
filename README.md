# 塔防（tafang）

仿《王国保卫战》的 2D 塔防游戏，使用 **Godot 4.7**（GDScript）开发。
多关卡模式：**6 个设计关卡**、开始界面、进度存档与星级评价、3 种防御塔、
建造/升级/出售、金币与生命、胜负结算、粒子特效、主题 UI、背景音乐。

## 打开与运行

1. 安装 Godot 4.7 或更高版本（本机使用 Steam 版 Godot 4.7.1）。
2. 打开 Godot 项目管理器 → **导入** → 选择本目录的 `project.godot`。
3. 打开项目后按 **F5** 开始游戏（主场景为开始界面 `scenes/start_menu.tscn`）。

命令行方式：

```bash
# 运行游戏（开始界面）
godot --path .

# 无头冒烟测试：10 倍速自动建造打穿指定关卡（0-5），输出每波状态与各塔开火统计
godot --headless --path . scenes/main.tscn --quit-after 7200 -- --smoke --level=0

# 截图模式：自动建塔开波，输出截图到 /tmp/tafang_*.png（对开始界面同样有效）
godot --path . scenes/main.tscn --quit-after 700 -- --shot --level=0
```

## 玩法

- 开始界面选择关卡（共 6 关：翠绿小径 / 河畔弯道 / 回旋谷 / 双峰峡谷 / 迷雾沼泽 / 王城决战），
  通关解锁下一关，按剩余生命评 1-3 星（≥18 命 3 星，≥12 命 2 星），进度自动存档
- 点击地图上的**石板建造点** → 建造菜单（箭塔 70 / 法师塔 100 / 炮塔 125）
- 点击已建的塔 → **升级**（最高 3 级）或**出售**（返还 70% 造价）；
  每个等级外观不同（法师塔更换导弹架造型，箭塔/炮塔染色并放大，另有等级黄点）
- 底部按钮**开始下一波**，波次结束后 **20 秒倒计时自动开波**
  （按钮上显示进度条与剩余秒数，随倍速缩放、暂停时冻结）；
  旁边按钮切换 **x1/x2/x3 倍速**
- 右上角：**菜单**（返回开始界面）、**测试**（加金币/生命、清空敌人、暂停/继续、音乐开关）
- 敌人冲进城堡扣生命（屏幕红闪提示），归零失败；守住整关全部波次获胜
- 存档位于 `user://save.json`（解锁进度与每关最高星级）

## 代码架构

```
project.godot          项目配置（主场景=开始界面、1920x1080、GameState 自动加载）
scenes/
  start_menu.tscn      开始界面（关卡选择）
  main.tscn            关卡场景（仅根节点，内容由代码生成）
scripts/
  game_state.gd        全局状态单例：当前关卡、解锁进度、星级、存档读写
  start_menu.gd        开始界面：标题 + 六关卡片（锁定/星级显示）
  main.gd              游戏主管理器：
                       - LEVELS 六关数据目录（路径/建造点/初始金币生命/血量成长/波次）
                       - _compose_waves() 参数化波次生成器（第 2-6 关）
                       - MapDrawer 内部类：地图绘制（草地/道路/装饰/城堡/射程预览）
                       - 波次调度、金币生命、建造/升级/出售
                       - 特效系统（粒子/爆炸/飘字/红闪）与全部 UI
  enemy.gd             敌人：沿路径移动、血条、受击闪白、出场/行进动效
  tower.gd             防御塔：索敌、平滑转向、待机扫视、开火后座、升级数值
  projectile.gd        投射物：追踪弹道、单体/溅射伤害、命中特效
assets/
  td/                  Kenney Tower Defense Top-Down 贴图（CC0）
  fx/                  Kenney Particle Pack 粒子贴图（CC0）
  ui/                  game-icons.net 图标（CC BY 3.0）
  audio/               背景音乐（CC BY 4.0）
```

### 关键设计

- **数据驱动关卡**：`main.gd` 的 `LEVELS` 目录集中定义六关的路径折点、建造点、
  初始资源与难度系数；城堡位置按路径末端方向自动推算；第 1 关使用手工波次
  `WAVES_L1`，第 2-6 关由 `_compose_waves(波数, 预算)` 生成
- **无场景文件依赖**：关卡内所有节点都在代码中构建，加新关卡只需在
  `LEVELS` 追加一个字典
- **建造点校验**：所有建造点到路径距离 ≤185（小于最短的炮塔射程 190），
  新设计关卡时应复核（可用脚本计算各点到路径折线段的最近距离）
- **特效/UI 复用**：`spawn_particles(pos, opts)` 一个函数组合出全部粒子效果；
  `_panel_style()` / `_style_button()` 统一深色金边 UI 风格
- **存档**：`GameState` 自动加载单例负责进度与星级，胜利时写入 `user://save.json`
